Entropy_Compression_Coding_Algorithms

Project Overview

This repository contains the implementation of Huffman and Shannon-Fano coding algorithms for the CIE 425 Information Theory and Coding course. The project involves analyzing a given text file, calculating character probabilities, entropy, and comparing the efficiency of fixed-length, Huffman, and Shannon-Fano codes.

Features

	1.	Symbol Probability Calculation:
Estimates the probabilities of 33 different characters in the provided text file, including lowercase letters and selected punctuation.
	2.	Entropy Calculation:
Computes the entropy based on the calculated symbol probabilities.
	3.	Fixed-Length Code Efficiency:
Calculates the number of bits per symbol and determines the efficiency of fixed-length coding.
	4.	Huffman Encoding/Decoding:
Custom implementation of Huffman encoding to generate a bitstream, and decoding to reconstruct the original text file.
	5.	Shannon-Fano Encoding/Decoding:
Implements Shannon-Fano encoding/decoding for the same text file and compares its efficiency with Huffman coding.
	6.	Efficiency Comparison:
Measures and compares the performance of both Huffman and Shannon-Fano coding algorithms.
